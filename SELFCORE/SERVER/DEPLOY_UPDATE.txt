================================================================
SCHRITT 1 — .env mit ALLEN Variablen erstellen
================================================================

Ersetze die Werte in Anführungszeichen mit DEINEN echten Daten!

cat > /var/www/genselfcore/.env << 'EOF'
# === SERVER ===
PORT=8001
NODE_ENV=production
JWT_SECRET=Selfcore2024SuperGeheimXyzAbcDef987!

# === E-MAIL (für Passwort-Reset) ===
# Option A: Gmail (einfachste Lösung)
#   1. Gehe zu myaccount.google.com → Sicherheit → 2-Faktor aktivieren
#   2. Dann: myaccount.google.com → Sicherheit → App-Passwörter
#   3. Neues App-Passwort erstellen → Das ist dein SMTP_PASS
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=deine.email@gmail.com
SMTP_PASS=dein-app-passwort-hier
SMTP_FROM=noreply@genselfcore.de

# === CLOUDFLARE R2 (für Audio-Streaming) ===
#   1. Gehe zu dash.cloudflare.com → R2 Object Storage
#   2. Bucket erstellen: "selfcore-audio"
#   3. R2 API Token erstellen (mit Read/Write Zugriff)
R2_ACCOUNT_ID=deine-cloudflare-account-id
R2_ACCESS_KEY=dein-r2-access-key
R2_SECRET_KEY=dein-r2-secret-key
R2_BUCKET=selfcore-audio
R2_PUBLIC_URL=https://selfcore-audio.deine-account-id.r2.cloudflarestorage.com

# === APPLE (für In-App-Purchase Validierung) ===
#   1. App Store Connect → Meine Apps → Shared Secret
#   2. Oder: appstoreconnect.apple.com → Users → Shared Secret
APPLE_SHARED_SECRET=dein-apple-shared-secret
EOF

echo "✅ .env erstellt"

SCHRITT 4 — server.js ersetzen
================================================================

WICHTIG: Der neue server.js ist zu lang für Copy-Paste.
Am einfachsten: Vom GitHub Repo direkt runterladen.

Option A — Direkt von GitHub (empfohlen):

cd /var/www/genselfcore
curl -o server.js "https://raw.githubusercontent.com/Testerking434/rust-maps/claude/explore-new-features-LZPos/SELFCORE/SERVER/server.js"

cd /tmp

================================================================
WICHTIG: WAS DU NOCH KONFIGURIEREN MUSST
================================================================

1. E-MAIL (SMTP_USER + SMTP_PASS):
   → Gmail: myaccount.google.com → Sicherheit → App-Passwörter
   → Oder: Einen E-Mail-Service wie Resend.com nutzen

2. CLOUDFLARE R2 (für Audio):
   → dash.cloudflare.com → R2 → Bucket "selfcore-audio" erstellen
   → API Token erstellen → Keys in .env eintragen
   → MP3-Dateien hochladen in den Bucket

3. APPLE SHARED SECRET (für In-App-Kauf):
   → appstoreconnect.apple.com → App → App-Spezifischer Shared Secret
   → In .env eintragen

Falls du einen Dienst NOCH NICHT nutzt, lass den Wert einfach
leer — der Server startet trotzdem (Feature ist dann deaktiviert).
